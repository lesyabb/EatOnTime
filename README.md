# EatOnTime

EatOnTime je webová aplikace, která pomáhá uživatelům s plánováním a přípravou vícechodového menu. Umožňuje zobrazit recepty, potřebné suroviny, postup přípravy a časový harmonogram jednotlivých jídel.

## Použité technologie

- **HTML5** – struktura webové aplikace
- **CSS3** – vzhled a responzivní design
- **JavaScript** – interaktivní funkce aplikace
- **JSON** – ukládání statických dat o receptech a menu
- **GitHub** – správa verzí a týmová spolupráce

## Struktura projektu

- `index.html` – úvodní stránka aplikace
- `css/` – soubory se styly
- `js/` – aplikační logika
- `data/` – data receptů a jednotlivých menu
- `assets/` – obrázky a další statické soubory

## Spuštění projektu

1. Naklonujte si repozitář do svého počítače.
2. Otevřete projekt ve Visual Studio Code.
3. Otevřete soubor `index.html` v prohlížeči.
4. Pro načítání dat ze souborů JSON používejte lokální vývojový server (například rozšíření Live Server).

## Pravidla týmové spolupráce

1. Před zahájením práce si stáhněte aktuální změny z větve `main`.
2. Pro každý úkol vytvořte samostatnou větev, například `feature/detail-receptu`.
3. Po dokončení změn vytvořte commit s výstižným popisem.
4. Nahrajte změny na GitHub a vytvořte pull request.
5. Před sloučením změn do větve `main` musí kód zkontrolovat alespoň jeden další člen týmu.

## Řízení projektu

Projekt je řízen pomocí agilních principů. Práce je organizována do sprintů a jednotlivé úkoly jsou evidovány v Jira.

## Aktuální rozsah

První verze aplikace bude využívat statická data receptů a menu. Potřeba backendu, databáze a hostingu bude vyhodnocena v průběhu vývoje.
